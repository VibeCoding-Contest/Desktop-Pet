## 二、IPC 通信协议（主进程 ↔ 渲染进程）

### 2.1 preload.js 暴露的 API

```js
// preload.js 通过 contextBridge 暴露给渲染进程的对象
window.petAPI = {
  // 窗口操作
  moveWindow:      (dx, dy) => ipcRenderer.send('move-window', dx, dy),
  setClickThrough: (enable) => ipcRenderer.send('set-click-through', enable),
  getWindowBounds: ()      => ipcRenderer.invoke('get-window-bounds'),

  // 数据持久化
  saveData: (data) => ipcRenderer.send('save-data', data),
  loadData: ()     => ipcRenderer.invoke('load-data'),

  // 托盘
  minimizeToTray: () => ipcRenderer.send('minimize-to-tray'),
  closeApp:       () => ipcRenderer.send('close-app'),

  // 事件监听（主进程 → 渲染进程）
  onTrayAction: (callback) => {
    ipcRenderer.on('tray-action', (_event, action) => callback(action));
  },
};
```

### 2.2 Channel 详细说明

| Channel | 方向 | 参数 | 说明 |
|---------|------|------|------|
| `move-window` | renderer → main | `(dx: number, dy: number)` | 相对移动窗口，用于拖拽 |
| `set-click-through` | renderer → main | `(enable: boolean)` | 开启/关闭鼠标穿透（true=穿透，不响应点击） |
| `get-window-bounds` | renderer → main | 无 | 返回 `{x, y, width, height}` |
| `save-data` | renderer → main | `(data: SaveData)` | 保存数据到 localStorage/JSON 文件 |
| `load-data` | renderer → main | 无 | 返回 `SaveData | null` |
| `minimize-to-tray` | renderer → main | 无 | 最小化到系统托盘 |
| `close-app` | renderer → main | 无 | 退出应用 |
| `tray-action` | main → renderer | `(action: string)` | 托盘菜单点击回调，action 值：`'show'` / `'exit'` |

## 三、EventBus 事件总线

所有渲染进程模块间通信通过 EventBus 完成，不直接引用彼此。

### 3.1 EventBus 接口

```js
class EventBus {
  /**
   * 注册事件监听
   * @param {string} event   - 事件名
   * @param {Function} callback - 回调函数
   */
  on(event, callback) {}

  /**
   * 移除事件监听
   * @param {string} event   - 事件名
   * @param {Function} callback - 回调函数（必须与 on 时传入的引用一致）
   */
  off(event, callback) {}

  /**
   * 触发事件
   * @param {string} event  - 事件名
   * @param {*}      data   - 事件数据
   */
  emit(event, data) {}
}
```

### 3.2 事件列表

| 事件名 | 发出者 | 携带数据 | 说明 |
|--------|--------|----------|------|
| `pet:stateChange` | pet.js | `{ state: string }` | 宠物动画状态变化 |
| `pet:moveEnd` | pet.js | `{ x: number, y: number }` | 宠物移动到新位置 |
| `pet:clicked` | pet.js | `{ x: number, y: number }` | 宠物被点击 |
| `pet:dragging` | app.js | `{ dx: number, dy: number }` | 拖拽中（告知 pet 更新位置） |
| `pet:dragEnd` | app.js | `{ x: number, y: number }` | 拖拽结束 |
| `status:change` | status.js | `{ hunger: number, mood: number }` | 属性值变化 |
| `status:hungry` | status.js | `{ hunger: number }` | 饱食度低于阈值（<30） |
| `status:starving` | status.js | `{ hunger: number }` | 饱食度严重不足（<10） |
| `status:sad` | status.js | `{ mood: number }` | 心情值低于阈值（<20） |
| `status:happy` | status.js | `{ mood: number }` | 心情值恢复高位（>80） |
| `status:fed` | status.js | `{ hunger: number }` | 喂食后 |
| `status:played` | status.js | `{ mood: number }` | 玩耍后 |
| `bubble:show` | app.js | `{ type: string, text?: string, x: number, y: number }` | 显示气泡 |
| `bubble:hide` | app.js | 无 | 隐藏气泡 |
| `menu:feed` | menu.js | 无 | 右键菜单选「喂食」 |
| `menu:play` | menu.js | 无 | 右键菜单选「玩耍」 |
| `menu:switchPet` | menu.js | `{ type: string }` | 右键菜单选「切换角色」 |
| `menu:exit` | menu.js | 无 | 右键菜单选「退出」 |
| `app:save` | app.js | 无 | 触发保存数据 |
| `app:load` | app.js | 无 | 触发加载数据 |

## 四、渲染进程模块接口

### 4.1 Pet（pet.js）— 角色核心

```js
class Pet {
  /**
   * @param {HTMLCanvasElement} canvas - 绑定的 Canvas 元素
   */
  constructor(canvas) {}

  // ----- 属性 -----
  /** @type {string} 当前动画状态：'idle' | 'walk' | 'jump' | 'sit' | 'yawn' | 'sad' */
  state

  /** @type {number} 角色在 Canvas 内的 x 坐标 */
  x

  /** @type {number} 角色在 Canvas 内的 y 坐标 */
  y

  /** @type {string} 当前角色类型：'cat' | 'dog' | 'penguin' */
  petType

  // ----- 方法 -----

  /**
   * 切换动画状态
   * @param {string} newState - 目标状态
   * @param {object} [options] - 可选参数
   * @param {boolean} [options.force=false] - 是否强制切换（即使状态相同也重新播放）
   */
  setState(newState, options = {}) {}

  /**
   * 帧更新（每帧调用，由 requestAnimationFrame 驱动）
   * @param {number} deltaTime - 距上一帧的毫秒数
   */
  update(deltaTime) {}

  /**
   * 绘制当前帧到 Canvas
   */
  draw() {}

  /**
   * 切换角色类型
   * @param {string} type - 'cat' | 'dog' | 'penguin'
   */
  setPetType(type) {}

  /**
   * 移动到指定位置（带走路动画）
   * @param {number} targetX
   * @param {number} targetY
   * @returns {Promise<void>} 移动完成后 resolve
   */
  moveTo(targetX, targetY) {}

  /**
   * 触发跳跃动画
   * @returns {Promise<void>} 跳跃完成后 resolve
   */
  jump() {}

  /**
   * 启动自动行为定时器（空闲 5 秒后随机触发）
   */
  startAutoBehavior() {}

  /**
   * 停止自动行为定时器
   */
  stopAutoBehavior() {}

  /**
   * 获取角色边界框
   * @returns {{ x: number, y: number, width: number, height: number }}
   */
  getBounds() {}

  /**
   * 销毁实例，清理定时器
   */
  destroy() {}
}
```

### 4.2 Status（status.js）— 状态系统

```js
class Status {
  constructor() {}

  // ----- 属性 -----
  /** @type {number} 饱食度 0-100（值越小越饿） */
  hunger

  /** @type {number} 心情值 0-100（值越小越差） */
  mood

  // ----- 方法 -----

  /**
   * 启动衰减计时器（每秒衰减）
   * @param {object} [options]
   * @param {number} [options.hungerDecay=0.5] - 每秒饱食度衰减量
   * @param {number} [options.moodDecay=0.3]   - 每秒心情值衰减量
   */
  start(options = {}) {}

  /**
   * 停止衰减计时器
   */
  stop() {}

  /**
   * 喂食，增加饱食度
   * @param {number} [amount=30] - 增加量
   */
  feed(amount = 30) {}

  /**
   * 玩耍，增加心情值
   * @param {number} [amount=10] - 增加量
   */
  play(amount = 10) {}

  /**
   * 序列化当前状态
   * @returns {{ hunger: number, mood: number }}
   */
  getData() {}

  /**
   * 从已保存数据恢复状态
   * @param {{ hunger: number, mood: number }} data
   */
  loadData(data) {}

  /**
   * 销毁实例，清理定时器
   */
  destroy() {}
}
```

   * 销毁实例，移除 DOM 元素

## 五、事件流转图

### 5.1 用户拖拽宠物

```
mousedown (canvas)
  → app.js: 标记 isDragging=true, 记录起始屏幕坐标
  → app.js: emit('pet:dragging', {dx, dy})
  → pet.js: 更新 this.x, this.y
  → app.js: 调用 window.petAPI.setClickThrough(false)  // 关闭穿透
  → app.js: 调用 window.petAPI.moveWindow(dx, dy)

mousemove (window)
  → app.js: 计算 dx, dy
  → emit('pet:dragging', {dx, dy})
  → app.js: window.petAPI.moveWindow(dx, dy)

mouseup (window)
  → app.js: 标记 isDragging=false
  → emit('pet:dragEnd', {x, y})
  → app.js: window.petAPI.setClickThrough(true)  // 恢复穿透
```

### 5.2 用户点击宠物

```
click (canvas)
  → pet.js: jump()
  → emit('pet:clicked', {x, y})
  → status.js: play(10)  → emit('status:played')
  → bubble.js: show('happy')
```

### 5.3 用户右键喂食

```
contextmenu (canvas)
  → menu.js: show(x, y)

click '喂食' (menu item)
  → emit('menu:feed')
  → status.js: feed(30)  → emit('status:fed')
  → bubble.js: show('feed')
  → menu.js: hide()
```

### 5.4 状态衰减触发提示

```
每秒定时器
  → status.js: hunger -= 0.5, mood -= 0.3
  → emit('status:change', {hunger, mood})

  if hunger < 30:
    → emit('status:hungry')
    → bubble.js: show('hungry')
    → pet.js: 可切换 sad 动画

  if mood < 20:
    → emit('status:sad')
    → bubble.js: show('sad')
```

### 5.5 自动行为

```
空闲 5 秒无操作
  → pet.js: 随机选择行为 (walk/sit/yawn)
  → emit('pet:stateChange', {state})
  → 播放对应动画，结束后回到 idle
```

## 六、数据持久化格式

### 6.1 SaveData Schema

```ts
interface SaveData {
  pet: {
    type: string;       // 'cat' | 'dog' | 'penguin'
    x: number;          // 窗口在屏幕上的 x 坐标
    y: number;          // 窗口在屏幕上的 y 坐标
  };
  status: {
    hunger: number;     // 0-100
    mood: number;       // 0-100
  };
  timestamp: number;    // 保存时间戳
}
```

### 6.2 保存/加载流程

```
保存时机：
  - 应用退出前（before-quit）
  - 用户点击「退出」菜单项
  - 窗口隐藏/最小化时

加载时机：
  - 应用启动时（app.js init() 中）

保存流程：
  app.js 收到退出信号
  → emit('app:save')
  → 收集 pet.getData() + status.getData()
  → window.petAPI.saveData(saveData)
  → 主进程写入 localStorage

加载流程：
  app.js init()
  → const data = await window.petAPI.loadData()
  → if (data) { pet.setPosition(data.pet.x, data.pet.y); status.loadData(data.status); }
```

## 八、三人分工与接口边界

```
人 A（窗口 & 交互框架）：
  对外暴露：main.js, preload.js, app.js, menu.js
  需要了解：EventBus 所有事件、IPC 协议
  不需要了解：pet.js / status.js / bubble.js 内部实现

人 B（角色 & 动画）：
  对外暴露：pet.js, Pet 类
  需要了解：EventBus 事件（pet:* 相关）
  不需要了解：main.js / preload.js / menu.js 内部实现

人 C（状态 & 数据）：
  对外暴露：status.js, bubble.js, Status 类, Bubble 类
  需要了解：EventBus 事件（status:*, bubble:* 相关）
  不需要了解：main.js / preload.js / menu.js 内部实现
```

### 联调接口清单

| 联调场景 | 依赖方 | 被依赖方 | 接口协议 |
|----------|--------|----------|----------|
| 拖拽移动窗口 | app.js (A) | main.js (A) | IPC `move-window` |
| 点击穿透切换 | app.js (A) | main.js (A) | IPC `set-click-through` |
| 数据持久化 | app.js (A) | main.js (A) | IPC `save-data` / `load-data` |
| 拖拽 → 更新宠物位置 | app.js (A) | pet.js (B) | Event `pet:dragging` |
| 点击 → 跳跃 + 心情 | app.js (A) | pet.js (B) + status.js (C) | Pet.jump() + Event `status:played` |
| 右键菜单 → 喂食/玩耍 | menu.js (A) | status.js (C) | Event `menu:feed` / `menu:play` |
| 状态衰减 → 提示气泡 | status.js (C) | bubble.js (C) | 内部直接调用 |
| 状态衰减 → 宠物动画 | status.js (C) | pet.js (B) | Event `status:hungry` / `status:sad` |
| 自动行为 → 气泡 | pet.js (B) | bubble.js (C) | Event `bubble:show` |

## 九、开发顺序建议

```
第 1 步：app.js 创建 EventBus 单例，各模块 constructor 接收 eventBus
       （所有人先确认 EventBus 接口，一人实现后其他人复用）

第 2 步：人 A 实现 main.js + preload.js（透明窗口 + IPC 通道）
       人 B 实现 pet.js 骨架（Canvas 渲染 + 帧动画）
       人 C 实现 status.js 骨架（属性 + 衰减）

第 3 步：app.js 串联所有模块，打通第一条完整链路：
       「拖拽移动」→ 所有模块联调

第 4 步：在此基础上逐功能叠加，按规划文档的阶段推进
```
