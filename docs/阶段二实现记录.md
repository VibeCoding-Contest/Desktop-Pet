### 2.1 气泡 CSS 动画（bubble.js + style.css）

**新增 3 种 keyframe 动画，按气泡类型自动匹配：**

| 动画类名 | 效果 | 触发类型 |
|----------|------|----------|
| `bubble--bounce` | 弹跳：先上弹再回落，0.5s | `happy` / `feed` / `play`（积极情绪） |
| `bubble--shake` | 左右抖动，0.5s | `hungry` / `starving`（饥饿抗议） |
| `bubble--wobble` | 左右摇摆，0.6s | `sad`（低落情绪） |

**CSS 实现：**

```css
/* 基础过渡：opacity + transform 0.2s */
.bubble {
  opacity: 0;
  transform: translateY(6px) scale(0.8);
  transition: opacity 0.2s, transform 0.2s;
}
.bubble--visible {
  opacity: 1;
  transform: translateY(0) scale(1);
}

/* 弹跳动画 */
@keyframes bubble-bounce {
  0%   { transform: translateY(0) scale(1); }
  30%  { transform: translateY(-8px) scale(1.08); }
  50%  { transform: translateY(0) scale(0.95); }
  70%  { transform: translateY(-4px) scale(1.03); }
  100% { transform: translateY(0) scale(1); }
}

/* 抖动动画 */
@keyframes bubble-shake {
  0%, 100% { transform: translateX(0); }
  15% { transform: translateX(-4px); } 30% { transform: translateX(4px); }
  45% { transform: translateX(-3px); } 60% { transform: translateX(3px); }
  75% { transform: translateX(-1px); } 90% { transform: translateX(1px); }
}

/* 摇摆动画 */
@keyframes bubble-wobble {
  0%, 100% { transform: rotate(0deg); }
  25% { transform: rotate(-3deg); } 50% { transform: rotate(3deg); }
  75% { transform: rotate(-2deg); }
}
```

**bubble.js 新方法：**

```js
_getAnimationClass(type) {
  switch (type) {
    case 'hungry': case 'starving': return 'bubble--shake';
    case 'sad':                    return 'bubble--wobble';
    case 'happy': case 'feed':
    case 'play':  default:         return 'bubble--bounce';
  }
}
```

## 自测验证

启动 `npm start`，在 DevTools 控制台运行：

```js
__test.feed()        // 喂食 → 弹跳气泡（feed 类台词）
__test.play()        // 玩耍 → 弹跳气泡（happy 类台词）
__test.lowHunger()   // 饥饿 → 抖动气泡（hungry 类台词）
__test.starve()      // 极度饥饿 → 抖动气泡「我要饿死了！！！」
__test.lowMood()     // 低落 → 摇摆气泡（sad 类台词）
__test.highMood()    // 高涨 → 弹跳气泡（happy 类台词）
__test.showBubble('hungry')  // 直接显示任意类型气泡
__test.listEvents()  // 查看事件注册表
```

### 动画效果验证

| 命令 | 预期动画 |
|------|----------|
| `__test.feed()` | 气泡从下方弹入，弹跳两次后稳定 |
| `__test.lowHunger()` | 气泡左右快速抖动 |
| `__test.lowMood()` | 气泡缓慢左右摇摆 |
| `__test.highMood()` | 气泡弹跳出现 |
