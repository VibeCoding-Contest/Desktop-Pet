## 各步骤实现详情

### 3.1 数据持久化（app.js）

**save 函数：**
```js
async function save() {
  const bounds = await window.petAPI.getWindowBounds();
  const data = {
    status: status.getData(),           // {hunger, mood}
    pet: bounds ? { x: bounds.x, y: bounds.y } : { x: 0, y: 0 },
    timestamp: Date.now(),
  };
  window.petAPI.saveData(data);         // IPC → main.js → JSON 文件
}
```

**load 函数：**
```js
async function load() {
  const data = await window.petAPI.loadData();  // IPC → main.js → 读取 JSON 文件
  if (data && data.status) {
    status.loadData(data.status);
  }
}
```

**保存触发时机（3 个入口）：**

| 触发方式 | 实现 |
|----------|------|
| 手动触发 | `eventBus.on('app:save', () => save())` |
| 菜单退出 | `eventBus.on('menu:exit', () => { save(); window.petAPI.closeApp(); })` |
| 窗口关闭 | `window.addEventListener('beforeunload', () => save())` |

**加载触发时机：**
- `init()` 中 `load()` 先于 `status.start()` 执行，确保恢复数据后再启动衰减

**IPC 链路（已由 A 在 main.js 中实现）：**
```
renderer: window.petAPI.saveData(data)
  → IPC 'save-data' → main.js: fs.writeFileSync('pet-save.json', data)
renderer: window.petAPI.loadData()
  → IPC 'load-data'  → main.js: fs.readFileSync('pet-save.json') → return data
```

### 3.3 状态栏 DOM（status.js + style.css）

**新增 `Status.createStatusBar(container)` 方法：**

- 动态创建 `.status-bar` DOM 元素，包含两条进度条
- 监听 `status:change` 事件实时更新进度条和数值
- 饥饿条（`status-bar__fill--hunger`）用橙色，心情条（`status-bar__fill--mood`）用粉色
- 低于阈值时添加 `status-bar__fill--low` 类名，变为红色警告

**DOM 结构：**
```html
<div class="status-bar">
  <div class="status-bar__item">
    <span class="status-bar__label">🍖</span>
    <div class="status-bar__track">
      <div class="status-bar__fill status-bar__fill--hunger" style="width:100%"></div>
    </div>
    <span class="status-bar__value">100</span>
  </div>
  <div class="status-bar__item">
    <span class="status-bar__label">💖</span>
    <div class="status-bar__track">
      <div class="status-bar__fill status-bar__fill--mood" style="width:100%"></div>
    </div>
    <span class="status-bar__value">100</span>
  </div>
</div>
```

**CSS 关键样式：**
```css
.status-bar {
  position: absolute;
  bottom: 4px; right: 6px;
  background: rgba(255,255,255,0.85);
  border-radius: 6px;
  padding: 3px 6px;
  z-index: 900;
}
.status-bar__fill--hunger { background: #ff9800; }
.status-bar__fill--mood   { background: #e91e63; }
.status-bar__fill--low    { background: #f44336; }  /* 低于阈值变红 */
```

**在 app.js 中启用：**
```js
load().then(() => {
  status.createStatusBar(document.body);  // 创建状态栏
  status.start();
});
```
