## Part A：Status 模块（1.1 ~ 1.4）

### 1.1 类骨架
- 构造函数接收 `eventBus`，初始化 `hunger=100`、`mood=100`
- `start(options)` — 启动衰减计时器，支持自定义衰减速率
- `stop()` — 停止计时器
- `feed(amount=30)` — 增加饱食度（上限 100）
- `play(amount=10)` — 增加心情值（上限 100）
- `getData()` / `loadData(data)` — 序列化与反序列化
- `destroy()` — 清理资源

### 1.2 衰减逻辑
- `setInterval` 每秒执行：hunger -= 0.5，mood -= 0.3
- 值域约束：`Math.max(0, value)` 防止负值

### 1.3 阈值检测
- 饱食度 < 30 → 触发 `status:hungry`
- 饱食度 < 10 → 触发 `status:starving`
- 心情值 < 20 → 触发 `status:sad`
- 心情值 > 80 → 触发 `status:happy`
- 通过 `_hungryFired` / `_starvingFired` / `_sadFired` / `_happyFired` 标志位防重复触发
- `feed()` / `play()` 调用 `_resetFlags()` 重置标志位

### 1.4 EventBus 集成
- 每秒衰减后 emit `status:change`（{hunger, mood}）
- 跨阈值时 emit 对应事件（`status:hungry` / `status:starving` / `status:sad` / `status:happy`）
- `feed()` 后 emit `status:fed` + `status:change`
- `play()` 后 emit `status:played` + `status:change`

### Status 对外接口

```js
const status = new Status(eventBus);
status.start();                          // 启动衰减
status.feed(30);                         // 喂食
status.play(10);                         // 玩耍
status.getData();                        // → {hunger, mood}
status.loadData({hunger: 50, mood: 60}); // 恢复状态
status.stop();                           // 暂停衰减
status.destroy();                        // 销毁
```

### Status 发出事件

| 事件 | 触发条件 |
|------|----------|
| `status:change` | 每秒衰减 / feed / play 后 |
| `status:hungry` | hunger 首次跌破 30 |
| `status:starving` | hunger 首次跌破 10 |
| `status:sad` | mood 首次跌破 20 |
| `status:happy` | mood 首次回升超过 80 |
| `status:fed` | feed() 调用后 |
| `status:played` | play() 调用后 |

## Part B：Bubble 模块（1.5 ~ 1.6）

### 1.5 类骨架
- 构造函数接收 `container`（DOM 元素），自动创建气泡 DOM 结构
- DOM 结构：`.bubble` > `.bubble-text` + `.bubble-arrow`
- `show(type, options)` — 显示气泡，内部随机选择台词
- `hide()` — 立即隐藏气泡
- `setPosition(x, y)` — 设置气泡位置
- `setQuotes(type, quotes)` — 注册自定义台词
- `destroy()` — 移除 DOM 元素

### 1.6 内置台词库（6 类 × 5 句 = 30 句）

| 类型 | 台词 | 触发场景 |
|------|------|----------|
| `happy` | 「今天天气真好~」「主人最好了！」「嘿嘿」「开心！」「好耶~」 | 心情高 / 点击互动 |
| `hungry` | 「好饿...」「有没有好吃的？」「肚子咕咕叫」「想吃东西了...」「饿瘪了 QAQ」 | 饱食度低 |
| `sad` | 「无聊...」「陪陪我嘛」「QAQ」「好孤单啊...」「呜呜」 | 心情低 |
| `idle` | 「发呆中...」「zzz...」「今天干点啥呢」「（盯——）」「...」 | 空闲时 |
| `feed` | 「好吃！」「谢谢主人！」「饱了饱了~」「再来一份！」「嗝~」 | 喂食后 |
| `play` | 「来玩吧！」「哈哈！」「好玩！」「再来一次！」「耶！」 | 玩耍后 |

### Bubble 对外接口

```js
const bubble = new Bubble(document.getElementById('bubble-container'));
bubble.show('happy');                             // 随机显示一条 happy 台词
bubble.show('hungry', { text: '我要饿死了！' });    // 自定义文本
bubble.show('idle', { duration: 5000 });           // 显示 5 秒
bubble.setPosition(100, 200);                      // 定位
bubble.setQuotes('custom', ['A', 'B']);            // 添加自定义台词
bubble.hide();                                     // 隐藏
bubble.destroy();                                  // 销毁
```
