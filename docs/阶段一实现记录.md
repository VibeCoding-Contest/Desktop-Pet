## 实现内容

### 1.1 类骨架
- 构造函数接收 `eventBus`，初始化 `hunger=100`、`mood=100`
- `start(options)` — 启动衰减计时器，支持自定义衰减速率
- `stop()` — 停止计时器
- `feed(amount=30)` — 增加饱食度（上限 100）
- `play(amount=10)` — 增加心情值（上限 100）
- `getData()` / `loadData(data)` — 序列化与反序列化
- `destroy()` — 清理资源

### 1.2 衰减逻辑
- `setInterval` 每秒执行：hunger -= 0.5，mood -= 0.3
- 值域约束：`Math.max(0, value)` 防止负值

### 1.3 阈值检测
- 饱食度 < 30 → 触发 `status:hungry`
- 饱食度 < 10 → 触发 `status:starving`
- 心情值 < 20 → 触发 `status:sad`
- 心情值 > 80 → 触发 `status:happy`
- 通过 `_hungryFired` / `_starvingFired` / `_sadFired` / `_happyFired` 标志位防重复触发
- `feed()` / `play()` 调用 `_resetFlags()` 重置标志位

### 1.4 EventBus 集成
- 每秒衰减后 emit `status:change`（{hunger, mood}）
- 跨阈值时 emit 对应事件（`status:hungry` / `status:starving` / `status:sad` / `status:happy`）
- `feed()` 后 emit `status:fed` + `status:change`
- `play()` 后 emit `status:played` + `status:change`

## 对外接口

```js
const status = new Status(eventBus);
status.start();                          // 启动衰减
status.feed(30);                         // 喂食
status.play(10);                         // 玩耍
status.getData();                        // → {hunger, mood}
status.loadData({hunger: 50, mood: 60}); // 恢复状态
status.stop();                           // 暂停衰减
status.destroy();                        // 销毁
```

## 发出事件

| 事件 | 触发条件 |
|------|----------|
| `status:change` | 每秒衰减 / feed / play 后 |
| `status:hungry` | hunger 首次跌破 30 |
| `status:starving` | hunger 首次跌破 10 |
| `status:sad` | mood 首次跌破 20 |
| `status:happy` | mood 首次回升超过 80 |
| `status:fed` | feed() 调用后 |
| `status:played` | play() 调用后 |
