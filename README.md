# 自定义形象（图片导入）使用指南

桌面桌宠支持**不改代码、不重新打包**地新增形象：选一张本地图片 + 填少量字段，即可在右键菜单「角色」中切换使用，重启后仍保留。

典型用例：导入一张科比照片 → 命名「科比」→ 右键切换 → 桌宠变成科比在桌面走动。

---

## 一、快速上手（3 步加一个形象）

1. **打开创建器**：在桌宠上**右键** → 鼠标移到「角色 ▸」→ 子菜单里点「**添加形象…**」。
2. **选图 + 填字段**：
   - 点「**选择图片…**」选一张本地图（推荐 **PNG 透明背景**，JPG 会有黑底）。
   - 「显示名」填你想看到的名字，如 `科比`。
   - 「ID」会自动从显示名生成；若是中文会自动降级为 `custom-xxx`，**可手改成英文/数字**（如 `kobe`），ID 必须唯一。
   - 「宽 × 高」选图后会按图片真实尺寸预填（上限 128），通常不用改。
   - 三个勾选项见 [§三 配置项详解](#三配置项详解)。
3. **注册并使用**：点「**注册并使用**」→ 桌宠立即变成新形象，并自动保存到磁盘。下次右键 →「角色 ▸」就能看到它，重启应用也还在。

> 预览框里有实时呼吸动画，改任何字段都会同步刷新，方便边填边看效果。

---

## 二、内置形象 vs 自定义形象

| 类型 | 来源 | 示例 |
|------|------|------|
| 内置 | 代码自带，随版本发布 | 猫咪 / 狗狗 / 企鹅 |
| 自定义 | 你用创建器导入的图片 | 科比 / 任意表情包 / 角色立绘 |

两者在右键菜单「角色 ▸」子菜单里**并列显示**，当前选中的会高亮。切换方式完全一致，享有的动画（idle 呼吸 / walk 摆动 / jump 跳跃 / sit 坐下 / yawn 打哈欠 / sad 难过）也完全一致——**图片形象会自动跟着引擎整体动**，不需要自己画关键帧。

---

## 三、配置项详解

创建器表单里的每一项含义如下：

| 字段 | 必填 | 默认 | 说明 |
|------|------|------|------|
| **显示名** (label) | 是 | — | 菜单里显示的文字，如「科比」 |
| **ID** (id) | 是 | 由显示名生成 | 形象唯一标识，仅允许 **字母 / 数字 / 连字符**，如 `kobe`。与内置形象重名会被拒绝 |
| **宽** (width) | 否 | 选图后按真实尺寸填，上限 128 | 绘制宽度（像素） |
| **高** (height) | 否 | 同上 | 绘制高度（像素） |
| ☐ **叠加引擎眼神** | 否 | 关 | 勾选后，图片上会按状态**额外画**引擎自带的眼神（idle 普通 / jump 圆睁 / sad 叉叉等） |
| ☐ **叠加引擎嘴部** | 否 | 关 | 勾选后，图片上会按状态**额外画**引擎自带的嘴（smile / o / frown / yawn） |
| ☑ **sad 时叠加泪滴** | 否 | **开** | 难过状态时在图片上叠加蓝色泪滴，与内置形象行为一致 |

### 三种典型搭配

- **保留原图神态**（推荐用于真人照片/表情包）：三个勾选项全关或只留「sad 泪滴」。
  → 图片是什么样就什么样，只在 sad 时加一滴泪。
- **让照片会眨眼/张嘴**（推荐用于角色立绘）：勾选「叠加眼神」+「叠加嘴部」。
  → 图片本身静止，但眼睛和嘴会随状态变化，更像活物。
- **纯图片不动**：全部关闭（包括 sad 泪滴）。
  → 完全靠引擎整体位移/呼吸，图片内部不变。

## 四、数据存在哪里

所有自定义形象存在 Electron 的 `userData` 目录下：

```
<userData>/custom-pets/
  ├── index.json          # 所有自定义形象的索引
  ├── kobe.png            # 各自的图片文件，文件名 = {id}.{ext}
  └── ...
```

`index.json` 结构示例：

```json
{
  "version": 1,
  "pets": [
    {
      "id": "kobe",
      "label": "科比",
      "imageFile": "kobe.png",
      "width": 64,
      "height": 64,
      "overlay": { "eyes": false, "mouth": false, "tear": true }
    }
  ]
}
```

- **不污染存档**：`pet-save.json` 只记当前选中的形象 id；自定义形象删了不影响存档结构（恢复时若 id 找不到会自动降级回「猫咪」）。
- 各平台 `userData` 路径：
  - Windows: `%APPDATA%\desktop-pet\custom-pets\`
  - macOS: `~/Library/Application Support/desktop-pet/custom-pets/`
  - Linux: `~/.config/desktop-pet/custom-pets/`

## 五、自动处理（你不用操心）

创建器在提交时会自动做这些事，无需手动操作：

1. **压缩**：图片用离屏 canvas 缩放到 ≤ 128px 并统一转 **PNG**，避免 base64 膨胀和显存压力。
2. **去重**：ID 相同会覆盖旧条目（索引 + 文件一起更新）。
3. **即时可用**：注册成功立刻能切换，落盘失败也不影响本次使用（会提示但不会回滚）。
4. **开机恢复**：下次启动会先加载所有自定义形象并注册，再恢复存档——所以存档里存的自定义 id 能正常恢复。

## 六、删除形象

目前创建器只做「新增」，删除走控制台命令（后续会做图形化管理面板）：

打开 DevTools 控制台（应用窗口聚焦时），运行：

```js
__test.listCustoms()                  // 先列出所有自定义形象的 id
__test.deleteCustomPet('kobe')        // 按 id 删除：移除菜单项 + 删磁盘文件
```

> 如果删的正是当前在用的形象，会自动切回「猫咪」。

## 七、排错

| 现象 | 原因 / 处理 |
|------|------|
| 提示「ID 已被占用」 | 该 id 与内置或已有自定义形象重名，改一个 |
| 提示「请选择图片」 | 还没选图，或图片加载失败 |
| 切换后图片不显示 | 图片正在加载，稍等片刻（首次切换有极短延迟） |
| 重启后自定义形象消失 | 索引文件被删/损坏，重新导入即可；或 `userData/custom-pets/` 目录无写权限 |
| 切到自定义形象后存档恢复失败 | 该 id 已被删除，系统会自动降级回猫咪 |
| JPG 图片有黑底 | JPG 不支持透明，请转成 **PNG**（推荐）或 WebP |

## 八、给开发者的契约说明

若你想用代码（而非 UI）新增形象，直接调用工厂即可：

```js
// renderer/pet-image-factory.js
registerCustomPet({
  id: 'kobe',                // 必填，唯一
  label: '科比',              // 必填，菜单文案
  imageSrc: 'data:image/png;base64,...',  // 创建时用 data URL；加载时用 file URL
  width: 64,                 // 可选，默认 64
  height: 64,                // 可选，默认 64
  overlay: {                 // 可选，默认全 false / tear true
    eyes: false,            // 是否叠加引擎眼神
    mouth: false,           // 是否叠加引擎嘴部
    tear: true,             // sad 是否叠加泪滴
  },
});
// 注册后即可 Pet 实例.setPetType('kobe') 切换
```

工厂返回的 renderer 契约 = `{ name, palette, init(): Promise, draw(ctx, o) }`，与内置 `cat/dog/penguin` 完全一致，引擎层零改动。详见 `docs/升级功能-自定义形象设计.md`。

## 九、后续扩展方向（当前版本不支持）

- 多帧精灵表（按状态分配不同图，实现真正的状态差异化动画）
